# Changelog

Every pull request adds **one new file** to this folder that says who you are and what you did.

## How to add yours

1. Copy [`_template.md`](_template.md).
2. Name the copy `your-github-username-short-title.md`, for example `priyapatel-dark-mode.md`.
3. Fill it in and include it in your pull request.

That's it! Because everyone creates their own file, you'll never get a merge conflict here.
